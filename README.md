# hxyfront-62005 管风琴音管调音记录

源提示词编号：7

给管风琴维护人员使用的单次维护工作台，替代纸质记录：

- **维护工作台**：选定场馆和日期后开始单次维护，逐根录入音栓、音管编号、音高、音分偏差、温湿度、簧片状态和维修备注；音分偏差超出该音栓允许范围时实时提示并自动标记异常。
- **维护报告**：维护完成后一键归档，自动生成报告页，汇总异常音管与处理建议（含偏差方向、簧片问题、温湿度环境提示），并保留全部录入明细快照，支持打印。
- **历史归档**：查看历次归档记录及其报告；归档数据为当时字段与异常判定的快照，不随后续修改变化。
- **复制草稿**：下一次维护可从该场馆上次归档数据复制草稿（工作台内一键复制，或报告页「据此新建下次维护草稿」），归档记录本身保持只读。

数据保存在浏览器 localStorage，刷新不丢失。

## 技术栈

React + Vite + TypeScript
