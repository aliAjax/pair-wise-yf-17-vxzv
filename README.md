# hxyfront-62005 管风琴音管调音记录

给管风琴维护人员使用的单次维护工作台，替代纸质记录。

## 功能

- **开工**：选定场馆（可新增）与维护日期，开始一次维护；可从该场馆上次维护复制草稿
- **逐根录入**：音栓（按主音栓/簧片音栓/混合音栓/低音管分组）、音管编号、音高、音分偏差、温度、湿度、簧片状态、维修备注；支持编辑与删除
- **自动异常标记**：每个音栓有允许偏差范围（±音分），录入偏差超限即实时标红为异常
- **归档与报告**：维护完成后一键归档，生成单次维护报告页——汇总异常音管与处理建议（调音方向、簧片处理、环境复测），附全部录入明细快照，可打印
- **历史回看**：归档记录只读保存当时的字段与异常结果；草稿可继续录入
- 数据保存在浏览器 localStorage，首次运行内置三条示例归档

## 技术栈

React + Vite + TypeScript
